# Политика конфиденциальности

Политика конфиденциальности учебного приложения «Итопиз». Редакция от 19.11.2026. Ответственная за обработку данных и разработчик: Хмеляр Екатерина Игоревна. Контакт для вопросов, помощи и обращений о данных: katerinaxmelar2402@gmail.com.

«Итопиз» — учебный тренажёр проверки знаний, пока не предназначенный для производственной эксплуатации. Данные используются для работы аккаунта, восстановления доступа, создания и подключения наборов вопросов, генерации по конспекту, сохранения результатов тренировок и ответа на обращения.

При регистрации приложение запрашивает имя, электронную почту и пароль. На сервере хранится хеш пароля. Для сохранения входа используются токены сессий. С аккаунтом связаны наборы вопросов, подключения и результаты тренировок; настройки приложения хранятся на устройстве.

При генерации сервер получает введённый текст или выбранный файл и извлекает из него текст. Текст передаётся в GigaChat для составления вопросов. Загруженный файл обрабатывается в памяти сервера; обработка переданного текста сервисом GigaChat регулируется также условиями этого сервиса. Проверяйте правильность сгенерированных вопросов и не загружайте персональные данные других людей или конфиденциальные материалы.

Для восстановления пароля сервер передаёт сервису Resend электронную почту получателя и содержание письма с одноразовым кодом. Рассмотрение обращений по электронной почте также предполагает обработку письма почтовыми сервисами. Сторонние сервисы обрабатывают полученные данные по своим условиям; их сроки хранения могут отличаться от сроков хранения в учебном приложении.

Если автор открывает доступ к набору и передаёт ключ другому пользователю, тот получает доступ к вопросам и ответам набора. Само подключение набора не открывает доступ к электронной почте и личным результатам автора.

Данные аккаунта и учебные результаты хранятся в течение использования аккаунта в учебном проекте, до обращения об удалении или прекращения обработки после завершения проекта. Обращения о данных рассматриваются лично разработчиком в сроки, предусмотренные применимым законодательством. Данные, для сохранения которых существует законное основание, могут храниться в пределах необходимого срока.

Для уточнения данных, отзыва согласия или удаления данных и аккаунта напишите на katerinaxmelar2402@gmail.com, желательно с адреса регистрации. Укажите суть запроса; при необходимости разработчик уточнит сведения для проверки принадлежности аккаунта. Не присылайте пароль и одноразовые коды. Отдельной кнопки удаления аккаунта в приложении нет. После удаления аккаунта связанные функции становятся недоступны.

Учебный статус не отменяет обязанностей по защите данных. Эта политика описывает текущие функции приложения и не подтверждает готовность инфраструктуры к публичной эксплуатации. При изменении целей, получателей или условий обработки политика должна быть обновлена.
