# Создание коллекции по конспекту

## Запуск

Библиотеки установлены в текущем проекте. При переносе проекта сначала выполни `npm ci` отдельно в папках `server` и `mobile`.

Сертификат из `server/certs/gigachat-ca.pem` теперь подключается автоматически при запуске `node index.js` или `npm start`, если `NODE_EXTRA_CA_CERTS` не задана. Команду ниже с переменной можно оставить, но вводить её каждый раз больше не обязательно. После обновления кода перезапусти сервер. Загрузка файлов использует `expo-file-system` File, совместимый с FormData в Expo 57.

На Android документ выбирается через DocumentPicker без копирования в кэш: имя берётся из метаданных, содержимое читается по выданному Android `content://` адресу. При отправке используется сам File с настоящим именем документа. Глобальный React Native Blob не создаётся: он не поддерживает конструирование из массива байтов. Это учитывает изоляцию кэша Expo Go и то, что адрес документа может содержать числовой ID вместо имени. На iOS используется FileSystem picker, в веб-версии — DocumentPicker. После обновления приложения выбери файл заново.

Генерация использует строгую JSON-схему GigaChat; если ответ не разбирается, сервер делает одну дополнительную попытку. Если модель вернула мало вопросов, сервер запрашивает недостающие, исключая повторы. Лишние вопросы не увеличивают выбранное количество. Общее число вызовов ограничено восемью; бесконечных повторов нет. Итог должен содержать точно выбранное число проверенных вопросов.

Если GigaChat недоступен через твой VPN, отключи VPN на компьютере перед генерацией или запуском проверочных команд. Эти команды сами обращения не запускают: их нужно выполнить вручную.

Проверить именно генерацию пяти вопросов, без телефона и без записи в БД, можно командой `node scripts/check-generation.js` из папки `server`. Эта проверка расходует токены API. При сетевой ошибке команда `node scripts/check-generation.js --network-debug` выводит только имя сервера и код сетевой ошибки, без ключа.

В первом окне PowerShell:

```powershell
cd D:\itpz
. .\dev-env.ps1
$env:NODE_EXTRA_CA_CERTS = 'D:\itpz\server\certs\gigachat-ca.pem'
cd server
node index.js
```

Если сервер уже работал, останови его через Ctrl+C и запусти заново. Настройки GigaChat остаются в `server/.env`.

Для телефона через USB во втором окне:

```powershell
cd D:\itpz
. .\dev-env.ps1
adb reverse tcp:3000 tcp:3000
adb reverse tcp:8082 tcp:8082
cd mobile
npm run start:usb -- --clear
```

Открой приложение через Expo Go. Выбери создание коллекции → «По конспекту».

## Использование

1. Введи уникальное название коллекции.
2. Укажи целое количество вопросов от 5 до 20. По умолчанию используется значение профиля, если оно доступно, иначе 10.
3. Выбери TXT (UTF-8), DOCX или PDF с текстовым слоем, либо вставь текст в поле.
4. Нажми «Составить вопросы». Генерация может занять несколько минут. Не закрывай страницу. Вызовы расходуют токены GigaChat.
5. Проверь вопросы, правильные ответы с отметкой ✓ и цитаты из конспекта. До сохранения результат находится на экране, в БД его ещё нет.
6. Нажми «Сохранить». Результат сохраняется в БД как личная коллекция, затем открывается список коллекций.
7. Если нужно исправить вопросы или настроить публичный доступ, открой сохранённую коллекцию и выбери редактирование.

Файлы до 10 МБ, извлечённый текст от 100 до 40 000 символов. Для PDF-сканов сначала нужно распознавание текста в другой программе. Файлы с паролем не поддерживаются. Если фактов мало, уменьши число вопросов или добавь материал.

Для связи с GigaChat интернет нужен серверу. Телефону достаточно связи с сервером, например по USB через adb reverse.

## Что сохраняется

В существующие таблицы `question_sets`, `questions`, `answer_options` записываются название, автор, вопросы и варианты ответов. Способ создания — `notes`. Сохранение выполняется существующей транзакцией: коллекция не записывается частично. Изменения схемы БД не нужны. Исходный файл и цитаты не архивируются; они используются при генерации и предпросмотре.

Сервер извлекает текст и отправляет его GigaChat без подключения поиска и внешних инструментов. Материал делится на фрагменты до 700 символов с номерами. Модель возвращает sourceId — номер фрагмента с основанием для ответа. Сервер проверяет существование номера и берёт исходный фрагмент для предпросмотра, не требуя от ИИ переписывать точную цитату. Генерация идёт порциями до 5 вопросов. Проверяются формат, точное количество, ограничения редактора и разные тексты вопросов. Существование ссылки на фрагмент не доказывает правильность вывода: смысл вопросов и ответов нужно проверить самостоятельно.

Ограничение: не более одной одновременной генерации на пользователя и 10 запусков за 10 минут. Неудачные попытки тоже учитываются. Задания выполняются в процессе сервера: при перезапуске или закрытии приложения несохранённый результат может потеряться. Это не фоновая очередь заданий.

## Код

- `server/collections/generate.js`: защищённый маршрут POST `/api/collections/generate`, приём файла и чтение текста.
- `server/collections/generation.js`: запросы к GigaChat и проверка результата.
- `mobile/src/screens/create-collection/GenerateCollectionScreen.jsx`: загрузка, выбор количества, предпросмотр, сохранение и переход к списку коллекций.
- POST `/api/collections`: существующее сохранение, теперь поддерживает метку `creationMethod: 'notes'`.
