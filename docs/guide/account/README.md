# Учётная запись

## Регистрация

1. На экране входа выберите «Регистрация».
2. Введите имя, адрес электронной почты и пароль.
3. Повторите пароль и подтвердите согласие на обработку данных.
4. Отправьте форму. Если появилось сообщение об ошибке, исправьте указанное поле.
5. После создания аккаунта войдите с указанной почтой и паролем.

Один адрес электронной почты используется для одной учётной записи.
Не передавайте другим людям пароль и код восстановления.

## Вход и восстановление доступа

Для входа укажите почту и пароль. Если пароль забыт, выберите «Восстановить пароль» и следуйте инструкции, отправленной на почту.
Проверьте папку «Спам», если письмо не пришло.

## Профиль и выход

В профиле можно посмотреть свои данные и общую статистику, изменить имя и пароль, выйти из аккаунта или запросить удаление учётной записи.
Для смены пользователя выполните выход, затем войдите в другой аккаунт.

## Доступ к данным

Редактировать набор может только его автор. Подключение чужого набора по ключу позволяет проходить его, но не изменять.
Результаты тренировок относятся к вашему аккаунту.
