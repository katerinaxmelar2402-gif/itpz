# Игровой бой

## Настройка

1. Выберите один или несколько доступных наборов.
2. Укажите начальное здоровье: обычно от 3 до 20, по умолчанию 8. Максимум для выбранного набора ограничен числом вопросов; если вопросов меньше трёх, нижняя граница также уменьшается. Начальное значение автоматически уменьшается до доступного максимума.
3. Укажите время ответа: от 5 до 120 секунд, по умолчанию 30 секунд.
4. Выберите порядок вопросов: по порядку или случайный.
5. Начните бой.

## Правила

Своевременный правильный ответ уменьшает здоровье противника на один пункт.
Неправильный ответ или истечение времени уменьшает ваше здоровье на один пункт.
Бой заканчивается победой при нулевом здоровье противника или поражением при нулевом вашем здоровье.

Если вопросы закончились раньше боя, они могут повторяться: сначала вопросы с ошибками, затем остальные.
Не считайте число показов равным числу уникальных вопросов.

## Пауза и завершение

Пауза останавливает текущий вопрос до возобновления.
При досрочном выходе подтвердите завершение: игра будет отмечена как прерванная.
При длительной потере связи бой может быть прерван; уже принятые сервером ответы сохраняются.
