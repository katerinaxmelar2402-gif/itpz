# История и работа над ошибками

## Результат боя

После завершения отображаются исход боя и сведения о принятых ответах.
В истории можно просмотреть прошлые прохождения, количество правильных ответов, ошибок и тайм-аутов, а также процент правильных ответов.
Повторные показы вопроса являются отдельными попытками ответа.

## Разбор ошибок

1. Откройте историю или статистику нужного набора.
2. Просмотрите вопросы, на которые ответили неправильно или не успели ответить.
3. Сверьтесь с учебным материалом.
4. Запустите работу над ошибками.
5. Ответьте на вопросы повторно.

Если неисправленных актуальных ошибок нет, специальное прохождение не требуется.

## Изменение набора

История прошедшей игры сохраняет формулировки, показанные во время той игры.
Автор может изменить набор, поэтому содержание нового прохождения может отличаться.

## Очистка статистики

Очистка статистики по выбранному набору требует подтверждения.
Перед подтверждением убедитесь, что выбрали нужный набор.
