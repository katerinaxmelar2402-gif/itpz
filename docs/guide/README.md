# Начало работы

Тренажёр помогает проверить, насколько хорошо вы запомнили изученный материал.
Вы отвечаете на вопросы с вариантами ответов, а результат ответа влияет на здоровье участников игрового боя.

## Кто может пользоваться приложением

До входа в аккаунт доступны регистрация, вход и восстановление пароля.
После входа доступны наборы вопросов, конспекты, игровой бой и личная статистика.
Административных экранов в мобильном приложении нет.

## Первая тренировка

1. [Создайте учётную запись](/guide/account/).
2. Откройте раздел создания вопросов.
3. [Введите вопросы вручную](/guide/questions/manual/) или [загрузите конспект](/guide/questions/generation/).
4. Проверьте вопросы и сохраните набор.
5. Выберите набор и запустите бой.
6. После завершения откройте статистику.

## Подключение к сети

Для входа, сохранения готовых наборов, генерации и игрового боя требуется связь с сервером.
Локальное сохранение незавершённого ввода помогает восстановить черновик, но не заменяет сохранение готового набора на сервере.
