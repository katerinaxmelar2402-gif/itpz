# Ручное создание вопросов

## Подготовка набора

1. Выберите создание набора вручную.
2. Введите название и тему.
3. Добавьте первый вопрос и заполните его текст.
4. Введите варианты ответа и отметьте ровно один как правильный.
5. Добавьте остальные вопросы и сохраните набор.

Не оставляйте пустых вариантов. Варианты должны различаться по смыслу, а вопрос должен иметь один однозначный ответ.

## Пример

Вопрос: «Какой компонент устройства выполняет вычисления?»

- Процессор — правильный ответ.
- Монитор — неправильный ответ.
- Клавиатура — неправильный ответ.
- Принтер — неправильный ответ.

## Если набор не сохраняется

Проверьте обязательные поля, варианты и отметку правильного ответа.
При сообщении об ошибке сети восстановите связь и повторите сохранение.
Черновик незавершённого ввода на устройстве не является подтверждением успешной отправки на сервер.
