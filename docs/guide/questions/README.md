# Наборы вопросов и архив

Набор объединяет вопросы по теме. В каждом вопросе есть один правильный и несколько неправильных вариантов ответа.

## Создание набора

- [Вручную](/guide/questions/manual/): введите вопросы и варианты самостоятельно.
- [По конспекту](/guide/questions/generation/): загрузите материал и проверьте предложенные вопросы.

Укажите название и тему, чтобы позже найти набор в архиве.
Готовый набор можно проходить несколько раз.

## Личный и публичный набор

Личный набор доступен только вам. Чтобы поделиться набором, измените его видимость на публичную и передайте другому пользователю ключ доступа.
Публичность набора не делает конспект и личные результаты общедоступными.

В настройках доступа можно отозвать ключ и создать новый.
Перевод набора в личный режим прекращает доступ других пользователей к новым прохождениям этого набора.

## Подключение чужого набора

1. Откройте действие подключения по ключу.
2. Введите полученный ключ без лишних пробелов.
3. Подтвердите подключение.
4. Найдите набор в архиве и начните тренировку.

Если набор не найден, проверьте ключ и уточните у автора, открыт ли доступ.

## Редактирование и удаление

Свой набор можно редактировать и удалять. Чужой подключённый набор можно убрать из своего архива.
Удаление подключения не удаляет исходный набор у автора.
