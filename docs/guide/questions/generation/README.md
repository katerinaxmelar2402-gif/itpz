# Генерация вопросов по конспекту

## Подготовка файла

Поддерживаются TXT, DOCX и PDF с текстовым слоем. Максимальный размер файла — 10 МБ.
Для проверки PDF попробуйте выделить и скопировать текст. Скан без распознаваемого текста для этой версии не подходит.
Презентации и старый формат DOC в эту версию не входят.

<u>Перед сохранением обязательно проверьте правильность вопросов и ответов.</u>

## Получение вопросов

1. Выберите создание набора по конспекту.
2. Укажите название и число вопросов: от 5 до 50.
3. Выберите файл и запустите генерацию.
4. Дождитесь завершения задания.
5. Прочитайте вопросы, исправьте неточности и удалите неудачные варианты.
6. Сохраните подготовленный набор и выберите его видимость.

Вопросы должны опираться на загруженный материал. Интернет-поиск для получения содержания вопросов не используется.
Если в конспекте недостаточно фактов, может потребоваться уменьшить число вопросов или загрузить более содержательный материал.

## Возможные ошибки

- Неподдерживаемый формат: сохраните материал как TXT, DOCX или PDF с текстом.
- Превышен размер: уменьшите файл.
- Текст не извлечён: проверьте, что файл не состоит только из изображений.
- Генерация завершилась ошибкой: повторите попытку позже или подготовьте набор вручную.
