# Интеллектуальный тренажёр проверки знаний

Курсовой проект мобильного приложения для повторения учебного материала. Идея проекта — превратить самопроверку в игровой бой. Пользователь составляет набор вопросов вручную или готовит его на основе конспекта, проходит тренировку и разбирает ошибки.

## Возможности проекта

- Создание и редактирование наборов вопросов.
- Генерация вопросов по конспекту с проверкой перед тренировкой.
- Подключение к чужим наборам по ключу доступа.
- Тренировки в формате игрового боя.
- Просмотр результатов и повторение вопросов, в которых были ошибки.

## Текущее состояние

Проект в разработке. В мобильной части доступен экран справки. Для сервера подготовлена начальная схема MySQL и реализована проверка подключения к базе через `GET /api/health`. Вход в аккаунт и игровые функции находятся в разработке.

## Локальный запуск

Понадобятся Node.js 22 (от 22.13), npm и MySQL 8.

В Windows перед запуском или установкой зависимостей выполни из корня проекта `.\dev-env.ps1` в каждом используемом окне PowerShell. Кэш npm, кэш компиляции Node.js, временные файлы Metro и кэш Gradle будут храниться в папке `.build-cache` на диске проекта.

### Мобильное приложение

Из корня репозитория выполните:

```sh
cd mobile
npm ci
npm start
```

### Запуск приложение через USB

В первом окне PowerShell запустите сервер:

```powershell
cd D:\itpz\server
node index.js
```

Проверьте ответ сервера (http://127.0.0.1:3000/api/health) на компьютере. В ответе должно быть `"database": "connected"`. Если вы используете другой `PORT` в `server/.env`, подставьте его также в адрес для телефона и в команду `adb reverse`.

Подключите телефон с включённой USB-отладкой. Во втором окне PowerShell выполните:

```powershell
adb devices
adb reverse tcp:3000 tcp:3000
adb reverse tcp:8082 tcp:8082
cd D:\itpz\mobile
npm run start:usb -- --clear
```

В списке `adb devices` телефон должен иметь статус `device`. Когда запустится Expo, нажмите `a` в терминале, чтобы открыть приложение на подключённом Android. `adb reverse` направляет запросы с телефона на локальные порты компьютера.
